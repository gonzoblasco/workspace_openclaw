# ROADMAP.md — AI Engineering Bootcamp

> Phase 3 — Product Roadmap
> Fecha: 2026-07-15

## Phase breakdown

### Phase 1: Traducir niveles a inglés + pulir docs — ~1 día
- **Goal:** Los 10 niveles en inglés, con formato consistente
- **Deliverable:** `docs/` completo en inglés
- **Tasks:**
  1. Traducir README.md a inglés
  2. Traducir cursor-vs-vscode.md a inglés
  3. Traducir levels 1-10 a inglés
  4. Estandarizar formato (objetivos, proyectos, self-reviews)
- **Skill:** agent-dispatcher

### Phase 2: Completar proyectos faltantes — ~1 día
- **Goal:** Los 23 proyectos con código funcional
- **Deliverable:** `projects/` con todos los proyectos implementados
- **Tasks:**
  1. Revisar qué proyectos tienen código y cuáles no
  2. Implementar los faltantes siguiendo las convenciones del bootcamp
  3. Verificar que cada proyecto compile y funcione
- **Skill:** agent-dispatcher

### Phase 3: README + branding — ~0.5 días
- **Goal:** README atractivo con progresión visual
- **Deliverable:** README.md + LICENSE
- **Tasks:**
  1. README con: qué es, para quién, tabla de progreso, cómo empezar
  2. LICENSE (MIT)
  3. Badges (GitHub stars, license, etc.)
- **Skill:** agent-dispatcher

### Phase 4: Repo público — ~0.5 días
- **Goal:** Repo en GitHub
- **Deliverable:** Repo público con initial commit
- **Tasks:**
  1. Crear repo
  2. Push initial commit
- **Skill:** agent-dispatcher

### Post-MVP
- Versión en español
- Screencasts / videos
- Foro de comunidad

## Risk register

| Riesgo | Impacto | Probabilidad | Mitigación |
|---|---|---|---|
| Poca adopción | Medio | Media | Promocionar en comunidades dev |
