# BRIEF.md — AI Engineering Bootcamp

> Phase 0 — Idea Intake
> Fecha: 2026-07-15

## Raw Idea

Un plan de estudio gamificado de 10 niveles para dominar el desarrollo asistido por IA. Originalmente creado para preparar una postulación como AI-Driven Engineering Specialist en Trafilea, usando VS Code + GitHub Copilot como equivalente a Cursor/Claude Code.

Actualmente existe como `projects/pr_vscode_niveles/` — 10 niveles documentados, 23 proyectos prácticos, algunos con código.

## Estado actual

- 10 niveles en `docs/` (level-01 a level-10)
- 23 proyectos prácticos definidos, algunos implementados en `projects/`
- `.github/copilot-instructions.md` con reglas del proyecto
- `.vscode/settings.json` con config de auto-approve
- Sin repo en GitHub
- Sin completar — es un roadmap, no un producto terminado

## Contexto

- Creado para postulación a Trafilea (puesto: AI-Driven Engineering Specialist)
- La metodología es transferible: VS Code + Copilot como equivalente a Cursor/Claude Code
- Gonzo ya tiene el conocimiento y la metodología — esto es material para compartir
- Se alinea con la estrategia de portfolio vivo: PRs a repos externos + contenido educativo
