# BRIEF.md — BrainWeb

> Phase 0 — Idea Intake
> Fecha: 2026-07-15

## Raw Idea

BrainWeb es un **gestor de notas PKM (Personal Knowledge Management)** con editor markdown, tags, y vista de grafo SVG. Actualmente es una app web standalone (TanStack Start + React 19) con persistencia solo en localStorage, generada en Lovable.

Repo: `github.com/gonzoblasco/brainweb-your-second-mind`

## Estado actual

- App funcional: notas, editor markdown con preview, tags, búsqueda, captura de links, import/export JSON
- Vista de grafo SVG (GraphView) que muestra relaciones entre notas
- Tema dark/light
- Sin backend, sin auth, sin sync multi-dispositivo
- Sin persistencia en servidor (todo localStorage)
- Sin deploy productivo
- Sin documentación de usuario

## Contexto del proyecto

- Es un proyecto público en GitHub de Gonzo
- Está en la categoría "proyectos de soporte" — al costado de los productos principales (SoporteML v2, UmbraWriter, ReActiva)
- No tiene definición de producto: no se sabe si es herramienta personal, SaaS, open source tool, o portfolio piece
