# Estudios de Ingeniería Narrativa

Este directorio agrupa los análisis de estructuras narrativas aplicando el **modelo de 4 ejes** (Premisa & Regla de Hierro, Gestión de Información, World‑building Funcional, Arco de Identidad).

Actualmente contiene un único sub-estudio:

* **Narrative-Engineering** - caso 03: *Mamma Mia!* (Broadway y película).

Más casos podrán añadirse en el futuro para validar la universalidad del modelo.
