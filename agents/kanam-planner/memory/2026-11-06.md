**Incidente Preflight (2026-11-06):**

- El review del CORE dijo que faltaban quota y cap de concurrencia; era cierto en el snapshot pre-fix. El commit `289cb19` (16:21:36) los agregó: quota en `src/lib/mcp.ts:25/100/135/247`, `src/lib/ratelimit.ts:19-20` (burst 3/min, daily 8); cap en `src/lib/scan.ts:38/43/52/100/104` (`MAX_CONCURRENT=4`, por proceso).
- Huecos que siguen reales: HTTP sin `PREFLIGHT_MCP_TOKEN` (fail closed), cap global entre réplicas, guard de CI para `readOnlyHint`, determinismo en contenedor, Chromium root/sandbox.
- Decisión: **no cambiar `gpt-oss:120b-cloud`**. El fix es el contrato de evidencia, no el modelo. Cada afirmación sobre código cita `archivo:línea` + commit/snapshot o se marca como supuesto; si no, se agrega un paso 0 de verificación. Un modelo más caro con el mismo brief repite el error, solo más rápido.
- Corrección para el roadmap del proyecto: `agents/kanam-planner/.knowledge/reviews/preflight-2026-11-06-correction.md`. El Planner no puede escribir fuera de su workspace; el CORE debe aplicar la corrección a `projects/preflight/.knowledge/ROADMAP.md`.

**Regla durable:** un plan no se dispatcha sobre supuestos. Estado actual = `archivo:línea` + commit/snapshot. Aplica al Planner y al review del CORE.
