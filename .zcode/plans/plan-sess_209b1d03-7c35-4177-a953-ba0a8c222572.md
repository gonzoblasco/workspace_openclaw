## Slice 7 — Fichas de personaje ricas + generación asistida (→ v0.3.0)

Objetivo: enriquecer el modelo `Character` (type tipado + campos nuevos + toggle de contexto) y agregar un flujo de generación asistida de personajes. Termina en release usable (build + tests pasan).

### 1. Data model (`types/index.ts`)
- Nuevo `CharacterType = 'protagonist' | 'antagonist' | 'supporting' | 'minor' | 'love_interest' | 'custom'`.
- `Character`: renombrar `role: string` → `type: CharacterType`; agregar `pronouns: string`, `groups: string[]`, `otherNames: string[]`, `traits: string[]`, `inContext: boolean`.

### 2. Migración DB (`lib/db.ts`)
- `DB_VERSION` 4 → 5.
- Bloque v4→v5 (patrón de la v3→v4, usando la `transaction` del versionchange): iterar `characters`, mapear `role`→`type` (helper `mapRoleToType`, default `supporting`), setear defaults (`pronouns:''`, `groups:[]`, `otherNames:[]`, `traits:[]`, `inContext:true`), `store.put`.

### 3. Labels (`lib/labels.ts`)
- `CHARACTER_TYPE_LABELS` + `characterTypeLabel(type)`.
- `mapRoleToType(role)` (mapea valores ES/EN conocidos → enum, default `supporting`).

### 4. Contexto (`lib/agentPrompts.ts`)
- `buildAgentContext`: filtrar `inContext === false`; usar `characterTypeLabel(c.type)`; incluir pronombres/otros nombres/grupos/rasgos.
- `buildGenerateCharacterPrompt(context, type?, instructions?)` (nuevo, estilo `buildSuggestBeatsPrompt`).
- Actualizar el schema de `add_character` (usa `type` + campos nuevos).

### 5. Parseo (`lib/agentReply.ts`)
- `parseSuggestedCharacterList` + `isValidSuggestedCharacter` (espejo de `parseBeatList`).
- Actualizar `isValidAction` para `add_character` (valida `type` enum + `name`).

### 6. Store (`lib/store.tsx`)
- `generateCharacter(type?, instructions?): Promise<Partial<Character>[]>` — contexto → prompt → `ollamaChat` → parse → drafts para preview.
- Actualizar `previewBibleCharacters`/`importCharactersFromBible` para `type` + campos nuevos.
- Agregar `generateCharacter` a `AppState` + value.

### 7. UI (`components/CharactersPanel.tsx`)
- `role` → `type` (select del enum) en edición.
- Campos nuevos: `pronouns` (textarea), `groups`/`otherNames`/`traits` (editores de tags), `inContext` (checkbox toggle).
- Botón **"Generate Character"** + preview/accept (espejo de OutlineView): modal con selector de Type + instrucciones + `Surprise Me`, preview Agregar/Regenerar/Descartar.

### 8. Renombres `role` → `type` en el resto
- `lib/prompts.ts` (21, 292), `lib/export.ts` (58), `lib/bibleExtract.ts` (5, 21, 74).

### 9. Tests
- Actualizar los existentes (`role` → `type`).
- Nuevos: `mapRoleToType`, `parseSuggestedCharacterList`, `buildGenerateCharacterPrompt`, filtro `inContext` en `buildAgentContext`.

### 10. Verificación + commit
- `npm run lint` → `npm test` → `npm run build` (secuencia pre-commit).
- Commit atómico en inglés + push (con `git pull --rebase`).

**Decisión que tomo (la señalo para que la valides):** el roadmap lista una tool `generate_character` para el chat, pero el chat **ya propone personajes vía `add_character`** (mismo efecto). Para no duplicar lógica, **reuso `add_character`** para el chat y el flujo dedicado de generación vive en la UI. Si querés una action `generate_character` separada, lo agrego.
