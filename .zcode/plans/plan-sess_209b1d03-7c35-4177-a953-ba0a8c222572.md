## Slice 2 — Outline & Beats

Objetivo: mapa de beats por capítulo/escena, editable a mano y sugerible por IA, conectado con la escritura y el chat. Termina en release usable (build + tests pasan).

### 1. Navegación: vista principal editor ↔ outline
- **Store** (`lib/store.tsx`): agregar estado de navegación `view: 'editor' | 'outline'`, `setView`, `currentOutlineChapterId`, `setCurrentOutlineChapterId` (mismo patrón que `settings`/`currentSceneId`).
- **`app/page.tsx`**: `<main>` renderiza `<Editor />` o `<OutlineView />` según `view`.
- **Topbar**: botón toggle Editor/Outline.
- **`ProjectTree.tsx`**: botón "outline" por capítulo (en el header del capítulo) → `setView('outline')` + `setCurrentOutlineChapterId(chapterId)`.

### 2. `OutlineView` (área principal) — vista + edición manual
- Nuevo `components/OutlineView.tsx` (estilo `.editor-shell`, tokens `--sl-*`).
- **Selector de capítulo** + botón **"Sugerir outline"**.
- **Mapa de beats** agrupado por capítulo y escena: beats de capítulo (`chapterId`) y de escena (`sceneId`).
- **Edición inline** por beat: `title`, `kind` (select), `status` (select), `description`, `notes`.
- **Reordenar**: botones ↑/↓ que intercambian `position` dentro del capítulo (helper `moveBeat`).
- **Agregar/Eliminar**: botón "+ Beat" por capítulo y por escena; trash por beat.
- Reusa el CRUD ya expuesto (`createBeat`/`updateBeat`/`deleteBeat`).

### 3. "Sugerir outline" (flujo dedicado, tool `suggest_beats`)
- **`buildSuggestBeatsPrompt`** en `lib/agentPrompts.ts`: contexto (proyecto + biblia + escenas del capítulo) pidiendo un array JSON de beats.
- **`parseBeatList`** en `lib/agentReply.ts`: parsea el array de beats (robusto, tolera prosa/fences).
- **Store `suggestBeats(chapterId): Promise<Beat[]>`**: llama `ollamaChat` (no-streaming), parsea, devuelve beats propuestos (con `chapterId`, `source:'ai'`, `position` asignada).
- **`OutlineView`**: muestra los beats propuestos como preview con **"Agregar"** (crea cada uno vía `createBeat`) / **"Descartar"**.

### 4. Conectar beats con la escritura
- **`Editor.tsx`**: strip bajo el resumen mostrando los beats de la escena actual (`sceneId === currentSceneId`), con el beat activo resaltado.

### 5. Discutir un beat en el chat
- Ya cubierto: el agente conoce los beats (`buildAgentContext` incluye el outline). Se deja funcionando; opcional un affordance mínimo por beat (no bloqueante).

### 6. Tests
- `buildSuggestBeatsPrompt` (incluye capítulo + biblia), `parseBeatList` (array, prosa, validación), `moveBeat`/reorder.

### 7. Verificación + commits
- `npm run lint` → `npm test` → `npm run build` (secuencia pre-commit).
- Commits atómicos en inglés (p.ej. `feat: outline view with manual beat editing`, `feat: suggest outline via agent`, `feat: show scene beats in editor`).
- Push al repo (con `git pull --rebase` antes, por el trabajo paralelo del otro agente).

**Fuera de alcance:** Biblia Viva (Slice 3), Brújula (Slice 4), drag-and-drop de beats (se usa ↑/↓), export.

**Nota:** Slice 2 es grande; lo implemento en sub-commits atómicos (vista+edición → sugerir → integración editor), cada uno verificado, para no romper el release usable.
