# ROADMAP — Psicólogo App

- [ ] Auth (login del psicólogo)
- [ ] CRUD de pacientes
- [ ] Agenda + calendario
- [ ] Recordatorios WhatsApp
- [ ] Registro de sesiones
- [ ] Dashboard
