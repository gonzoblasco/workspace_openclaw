# BRIEF — AI Developer Stack

## Idea Central

Un stack curado de 80+ skills, prompts y workflows battle-tested para operacionalizar ingeniería de alto nivel con IA. No es una colección de prompts — es un sistema de ingeniería.

## Problema que Resuelve

- Los desarrolladores que usan IA como copiloto no tienen un framework sistemático para aplicarla a cada dominio de ingeniería
- El "vibe coding" produce deuda técnica que nadie sabe limpiar
- No existe un blueprint unificado que cubra desde arquitectura hasta testing pasando por frontend, backend, automatización y producto
- Cada skill individual es útil, pero sin un playbook que las conecte, el valor es fragmentario

## Público Objetivo

- **Primario:** Desarrolladores fullstack que usan IA como infraestructura de trabajo (no como chat)
- **Secundario:** Indie hackers construyendo MVPs con Lovable/Supabase
- **Terciario:** Cualquier ingeniero que quiera un framework battle-tested para su dominio

## Diferenciación

- No es "otra colección de prompts" — es un sistema con playbooks, ciclos de vida y skills interconectadas
- Cubre TODO el ciclo de ingeniería: ideación → arquitectura → backend → frontend → testing → automatización → producto → crecimiento
- Skills diseñadas para ser consumidas por agentes de IA (no solo humanos)
- Battle-tested en proyectos reales

## Estado Actual
