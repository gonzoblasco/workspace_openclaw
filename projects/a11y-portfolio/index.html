02El sistema — cómo trabajo la accesibilidad

No es "agregar atributos". Es un proceso con criterio técnico y validación empírica.

Detectar el fallo real, no el síntoma

En astryx #4298 el problema no era "falta un label" — era que el status perdía significado para screen readers al componerse (parent-reads-child, issue #4777).

Entender la spec

WCAG 2.1 SC 1.4.1 (use of color), 1.4.11 (non-text contrast), 2.1.1 (keyboard). Cada fix cita su criterio.

Resolver con la jerarquía correcta

Prop explícita > default por variante > none. Nunca romper la semántica del sistema (lección del PR #4703: filled ≠ selected).

Validar empíricamente

Tests de locale override, tests de keyboard nav, verificación con screen readers (VoiceOver/NVDA) cuando el fix lo amerita.

Documentar el por qué

Changesets, i18n catalog, comentarios que explican la decisión, no solo el cambio.
