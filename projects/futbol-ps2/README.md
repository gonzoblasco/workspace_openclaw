# Fútbol 3D PS2-like

Un juego de fútbol 3D con cámara dinámica al estilo FIFA / Pro Evolution Soccer de PlayStation 2.

**Motor:** Godot 4.4+
**Lenguaje:** GDScript
**Estado:** 🟡 En desarrollo (Fase 0 — Setup)

## MVP

Partido humano vs CPU, 5 minutos, 11 vs 11, cancha 3D, cámara dinámica, controles teclado.
