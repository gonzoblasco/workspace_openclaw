# BRIEF — Pro Motors

> Sitio web para concesionario oficial multi-marca de vehículos.

## Contexto

**Pro Motors** es un concesionario oficial con más de 25 años en Vicente López, Buenos Aires. Representa las marcas KTM, Husqvarna, Can-Am, Sea-Doo, Ski-Doo y Segway. Tienen un local físico de 2.200 m² con showroom, postventa, repuestos e indumentaria.

## Canales actuales

- **Web:** pro-motors.com.ar (WordPress, template genérico)
- **Tienda Nube:** promotors.mitiendanube.com (accesorios, repuestos, indumentaria)
- **Mercado Libre:** (venta de vehículos)
- **Redes:** Instagram (@ktmpromotors, @husqvarnapm)
- **WhatsApp:** ventas, postventa, repuestos

## Problema

El sitio actual es un template WordPress que no refleja la calidad de las marcas premium que representa. No hay integración entre canales (ML, Tienda Nube, web). La experiencia está fragmentada.

## Objetivo

Crear un sitio web desde cero, fullstack, que:
- Refleje la calidad de las marcas (KTM, Can-Am, Husqvarna, Sea-Doo, Ski-Doo, Segway)
- Integre los canales de venta existentes (ML, Tienda Nube) como secciones dentro del sitio
- Sirva como herramienta de promoción y captación de leads
- Incluya features con IA (consultas, recomendaciones, etc.)
- Sea mantenible por los vendedores del local (sin conocimientos técnicos profundos)

## Estrategia

- **Regalo para el hermano** (sorpresa)
- **Costo operativo:** ~500 USD/mes (servidor + IA + otros)
- **Sin apuro:** priorizar calidad sobre velocidad
- **Rebuild completo** desde cero, no mejora sobre WordPress

## Preguntas resueltas

| Pregunta | Respuesta |
|----------|-----------|
| ¿Rebuild o mejora? | Rebuild completo desde cero |
| ¿Quién mantiene? | Vendedores del local (no técnicos) |
| ¿Apuro? | No, priorizar calidad |
| ¿Sorpresa? | Sí, es un regalo |
| ¿Stack? | Fullstack (definir en evaluación) |
| ¿IA? | Sí, consultas y otras features |
