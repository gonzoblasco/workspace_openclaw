# ADR-002: Storybook Integration Strategy

## Decision

Use `@storybook/addon-docs` for auto-generating docs from component README files, with addon-a11y integration.

## Contexto

Accesible-ui necesita documentación completa que mantenga al día con el codegen. Usar Storybook nativo nos permite:
- Docs 1:1 con source code
- Ejemplos de uso reales en stories
- ARIA audit automático en addon-a11y panel

## Decision

```typescript
// .storybook/preview.ts
import type { Preview } from "@storybook/react";
import docs from "./docs.mjs";

export const parameters = {
   ...getStorybookParameters(),
   ...docs, // auto-docs from component README files
};

function getStorybookParameters() {
   return {
      "a11y": {
         config: "@storybook/addon-a11y",
         violations: (violations) => [
            { title: "Must pass axe-core audit", description: violations.length > 0 ? `${violations.length} violations found` : "✅ Zero violations" },
         ],
      },
   };
}
```
