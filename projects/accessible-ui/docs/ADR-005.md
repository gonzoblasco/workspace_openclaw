# ADR-005: GitHub Actions CI/CD Strategy

## Decision

Set up GitHub Actions for three-phase CI/CD pipeline.

### Phase 1: Lint & Test (on pull request)
```yaml
name: PR Check
on:
   pull_request:
     branches: [main, develop]
steps:
   - uses: actions/checkout@v4
   - uses: actions/setup-node@v4
   - run: npm ci
   - run: npm run lint
   - run: npm test -- --run
```

### Phase 2: Build (on main branch)
```yaml
name: Build
on:
   push:
     branches: [main]
steps:
   - uses: actions/checkout@v4
   - uses: actions/setup-node@v4
   - run: npm ci
   - run: npm run build
```

### Phase 3: Publish (on main with release)
```yaml
name: Publish
on:
   release:
     types: [created, published]
steps:
   - uses: actions/checkout@v4
   - uses: actions/setup-node@v4
   - run: npm ci
   - run: npm version ${{ github.event.release.name }}
   - uses: docker/metadata-action@v4
   - uses: docker/build-push-action@v4
   - run: npx semantic-release
```

## Contexto

- **Lint**: TypeScript + ESLint (strict TS config from tsconfig.json)
- **Test**: Vitest with axe-core violations check
- **Build**: Vite optimize for production
- **Publish**: npm publish with `@gonzoblasco/` scope, release notes from changelog

## Decision Rationale

Vite is chosen as the build system because:
- Faster builds than Webpack/Rollup
- Modern tooling support (React 19+)
- Easy plugin ecosystem for Storybook integration
