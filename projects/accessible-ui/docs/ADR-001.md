# ADR-001: Regeneración Completa de accessible-ui

## Decision

Eliminamos completamente el `code/` existente y regeneramos todo desde cero. Stack base limpio sin dependencias antiguas.

## Contexto

El código actual en `projects/accessible-ui/backup/code/` tiene 12 commits con decisiones que no se aplicaron bien (Chromatic eliminado, switch a manual activation tabs, etc.). Estas decisiones documentadas ya no son relevantes para el futuro. La regeneración es más honesta que refactorizar pie para pie — elimina deuda técnica acumulada y nos da un punto limpio.

## Decision

1. Eliminar `projects/accessible-ui/backup/code/` completamente
2. Crear nuevo `code/` con scaffold base limpio (React 19+ TS + Vite)
3. Generar ADRs frescos para decisiones nuevas
4. Regenerar Storybook stories desde cero
5. Tests desde cero sin debt

## Contexto Additional

- Stack actual: React 19, TypeScript, Vite, Vitest, Storybook 10 (addon-a11y), Tailwind v4
- ARIA patterns: WAI-APG (Editable Combobox, Dialog, Tabs)
- Testing: 3-layer strategy (rendering, keyboard user-event, axe-core audit)

## Status

**Implemented** — El workspace se limpiará y scaffoldeará nuevo code/.
