# ADR-003: Testing Strategy Implementation

## Decision

Implement three-layer testing strategy with Vitest + @testing-library/react + jest-axe.

## Contexto

El testing es el componente crítico de cualquier librería headless. Sin tests adecuados, no podemos garantizar ARIA compliance real.

## Decision

### Layer 1: Rendering (Vitest)
```typescript
import { render } from "@testing-library/react";
import { axe } from "jest-axe";

describe("Combobox rendering", () => {
   test("has correct ARIA role", async () => {
      const result = await render(<Combobox options={...} />);
      expect(result.asTheDOM).toHaveRole("combobox");
   });
});
```

### Layer 2: Keyboard User-Event
```typescript
import { userEvent } from "@testing-library/user-event";

test("toggle panel on Enter key", async () => {
   const user = userEvent.setup();
   await user.type(
      <Combobox options={[]} />
   ); // Simulate typing
   await user.click(
      input.element
   ); // Open panel
});
```

### Layer 3: Axe Audit
```typescript
import { axe } from "jest-axe";

test("passes axe-core audit", async () => {
   const result = await render(<Combobox />);
   const results = await axe(result.asTheDOM.body) as Array<unknown>;
   expect(results).toHaveNoViolations();
});
```
