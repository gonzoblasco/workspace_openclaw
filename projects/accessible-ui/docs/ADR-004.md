# ADR-004: Build System Configuration Strategy

## Decision

Use Vite for build system, with optimized bundle output to `dist/` directory. Bundle target ES2022 for modern browser compatibility.

## Contexto

The regeneration needs a reliable build pipeline that produces npm-ready packages. Vite provides zero-config bundling (just copy package.json scripts).

## Decision

```json
{
   "target": "ES2022",
   "format": "module", // ES modules for modern Node support
   "outDir": "dist",
   "assetsInlineLimit": 4096, // inline small files to reduce bundle size
}
```

## Rationale

- **Zero-config**: Scripts from package.json work out-of-the-box
- **Modern bundling**: Vite's rolling build is much faster than Webpack/Rollup
- **Small output**: Optimized bundles (Vite devtools + module splitting)

## Implementation

```bash
# Build for distribution
npm run build  # outputs to dist/

# Production optimize
npm run build -- -m --sourcemap --minify
```
