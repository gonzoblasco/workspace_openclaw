# ADR-007: Testing Architecture Specification

## Decision

Implement three-layer testing architecture with strict separation of concerns. Each layer has different responsibilities and tooling.

### Layer 1: Unit Tests (Vitest + @testing-library/react)

```typescript
// Testing component rendering structure
describe("Combobox", () => {
   test("has combobox role when rendered", () => {
      render(<Combobox options={[]}>Test</Combobox>);
      expect(screen.getByRole("combobox")).toBeInTheDocument();
    });
    
   test("displays filtered list when input typed", async () => {
      const user = await userEvent.setup();
      render(<Combobox options={[{ value: "apple" }, { value: "banana" }]} />);
      await user.type(screen.getByRole("combobox"), "ap"); // Debounce 300ms
      expect(screen.getByRole("option")).toBeInTheDocument();
    });
});
```

### Layer 2: Keyboard Event Tests (user-event)

```typescript
test("navigates options with keyboard", async () => {
   const user = await userEvent.setup();
   render(<Combobox options={[]}>Test</Combobox>);
   // Simulate full keyboard sequence
   await user.keyboard(["ArrowDown"]);
   expect(screen.getByRole("option")).toBeFocused();
});
```

### Layer 3: Accessibility Audit (axe-core)

```typescript
test("passes WCAG AA compliance", async () => {
   render(<Combobox options={[]}>Test</Combobox>);
   const results = await axe(screen.getByRole("combobox")) as Array<unknown>;
   expect(results).toHaveNoViolations();
});
```

### Test File Structure

| Filename | Purpose |
|----------|---------|
| `Combobox.test.tsx` | Full component tests (render + keyboard) |
| `use-combobox.test.ts` | Pure hook function tests (no UI) |
| `Combbox-audit.ts` | axe-core violations only |
