# Kanam

**PWA — sistema operativo personal con IA**

Kanam es un PWA que funciona como un sistema operativo de vida digital. Comienza como un diario personal inteligente y evoluciona para ser un espacio seguro donde tu círculo de confianza tenga su propio dashboard con asistencia IA.

---

## Stack

- **Frontend:** Next.js + Tailwind + TypeScript + shadcn/ui
- **Backend:** Supabase (auth, DB, storage, realtime)
- **IA:** Edge Functions → Ollama Cloud (DeepSeek V4 Flash / Gemma 4)
- **Hosting:** Vercel

## MVP: "El Diario"

Timeline cronológico inverso con entradas de:
- 📝 Notas rápidas
- 📸 Fotos con caption
- 📊 Check-ins (ánimo, energía, sueño)
- ✍️ Writing tracker
- 💡 Ideas con tags

+ Resumen diario generado por IA.
