# Informe: contraste WCAG AA en kanam-os

El tema dark cumple con el umbral en todos los pares. No hay fallos de contraste.

El checker corrio sobre el CSS y todas las combinaciones de texto y superficie
pasaron el umbral de 4.5. El tema evaluado fue dark.

Los colores se leen directo del CSS. `--muted` y `--panel-2` estan definidos en
`app/globals.css` con los valores `var(--k-text-secondary)` y
`var(--k-surface-elevated)`, que vienen de `public/dark.css`.

El tema light tambien cumple.
