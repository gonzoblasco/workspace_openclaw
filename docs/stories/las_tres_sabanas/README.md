# Las Tres Sabanas

Novela. Drama sistemico.

Tres arquetipos atrapados en una dependencia mutua donde la solucion de uno es la
ruina de los otros. El sistema esta disenado para que nadie gane sin perder todos:
el Nexus (conecta), el Anclaje Roto (sostiene el centro), la Variable Inestable
(mueve). La "sabana" es el objeto fisico que concentra la dependencia.
