# Las Tres Sabanas

Novela. Drama sistemico.

Tres primos lejanos atrapados en una dependencia mutua donde la solucion de uno es la
ruina de los otros. Los une la sangre, ese algo que persiste aunque el sistema los
distancie. El sistema esta disenado para que nadie gane sin perder todos:
**Nestor** (el Nexus, conecta), **Adan** (el Anclaje Roto, sostiene el centro),
**Vera** (la Variable Inestable, mueve). La "sabana" es el objeto fisico que
concentra la dependencia.

## Canon

- Los tres tienen nombre: **Nestor** (Nexus), **Adan** (Anclaje Roto), **Vera** (Variable Inestable).
- Son **primos segundos** (bisabuela comun: Elvira Vergara), criados en ramas separadas por un pleito de herencia. Nestor y Vera se criaron un tramo como hermanos; Adan, no.
- El objeto que los ata: las **tres sabanas** que Elvira cosio antes de morir, una por rama.
