# ADR-002: Openspec Primary Doc Format

**Status:** Accepted  
**Deciders:** Gonzo / Kanam  
**Fecha:** 2026-07-19  
**Origen:** kanam-workflow

## Decision

Adopt OpenSpec (`.md` format with structured frontmatter) as the primary documentation format across all product pipeline stages, replacing fragmented markdown files and ad-hoc artifacts.

## Context

During sdd-brownfield and ai-copilot-structure integration, Gonzo's products (BrainWeb, SoporteML v2, KanamAI) have accumulated documentation in multiple formats:
- Standard `.md` without frontmatter
- YAML frontmatter with inconsistent keys
- JSON configs embedded in markdown
- Separate BRIEF/DEF/EVAL files with no consistent schema

This fragmentation creates maintenance overhead and makes the knowledge graph difficult to traverse. Gonzo's existing experience with OpenSpec v0.7.0 has shown significant benefits over standard markdown.

## Consequences

1. **Unified schema**: All product specs use OpenSpec frontmatter:
   ```yaml
   ---
   type: brief|definition|evaluation|roadmap
   slug: <product-slug>
   version: 1.0
   status: proposed|active|archived
   author: gonzo
   created: 2026-07-19
   related: [ADR-001, ADR-002]
   ---
   ```

2. **Searchability**: Frontmatter metadata enables querying across all specs in `projects/` and `docs/` directories

3. **Pipeline integration**: Skills like `sdd-brownfield` and `ai-copilot-structure` can directly manipulate structured docs without parsing arbitrary markdown content

4. **Versioning**: Specs inherit from git history, providing audit trail for decisions

## Implementation Notes

```bash
# Create spec with OpenSpec frontmatter:
cat > projects/<product-slug>/docs/BRIEF.md << 'EOF'
---
type: brief
slug: brainweb-v2
version: 1.0
status: proposed
author: gonzo
created: 2026-07-19
related: [ADR-001]
---

# BrainWeb v2 - Product Brief

## Problem Statement
...
EOF

# Update status via pipeline skill:
product-reset --update-spec BRIEF.md --status active --message "Foundation phase started"

# Query all specs for a project:
find projects/brainweb-v2/docs -name "*.md" -exec grep "^---$" {} \; | head -n 100 | tail +50
```
