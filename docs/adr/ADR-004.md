# ADR 004: Growth Strategy Triggers & Pivot Criteria

**Status:** Accepted  
**Deciders:** Gonzo / Kanam  
**Date:** 2026-07-19  

## Decision

Establish explicit criteria for when `product-orchestrator` should recommend continuing growth vs. triggering a full product reset (pivot).

## Context

In the Product Pipeline workflow, after launch metrics are collected, Gonzo must decide:
- **Continue**: Scale existing feature set with marketing/content
- **Pivot**: Reorient product based on market feedback (may involve new spec work)

Without clear thresholds, teams tend toward:
- Scaling what's easy instead of what matters
- Missing pivot windows due to overconfidence
- Resource exhaustion before learning meaningful signals

## Consequences

1. **Objective go/no-go gates**: Metrics-based decisions override sentiment
2. **Faster pivots**: Recognize when growth isn't sustainable without analysis
3. **Reduced waste**: Stop wasting resources on non-viable scaling efforts
4. **Consistent strategy application**: All products treated with same evaluation rigor

## Growth Continues vs. Pivot Criteria

### Continue Growing (Green) ⬆️
- Core metrics ≥ baseline × 1.5x over last 2 weeks
- Positive cohort retention (>70% of users return)
- At least one feature showing >3x engagement lift
- User feedback consistently positive (≥80% sentiment score)

### Pivot Required (Yellow → Red) ⚠️🔴
```
Condition: Core metrics < baseline OR negative cohort signal
Action: Trigger product-reset with PIVOT phase, new spec required
Decision gate: re-evaluate in 2 weeks or hard pivot mandatory after 3 weeks
```

### Hard Pivot (Red) 🔴
- **Definition**: Product fundamentally misunderstood market needs
- **Signal**: <50% retention for 2 cycles OR critical feature consistently rejected
- **Action**: Complete product reset → foundation restart with new spec
- **Constraint**: No revenue recovery possible in current direction

## Implementation Notes

```bash
# Check growth health:
product-orchestrator --evaluate-growth TARGET brainweb-v2 \
     --metrics {retention:78,cohort_return:85,sentiment:92} \
     --result GREEN --message "Scale existing feature set"

# Trigger pivot assessment:
product-orchestrator --trigger-pivot TARGET brainweb-v2 \
     --reason "Negative cohort signal detected"

# Hard pivot flag:
kanam-pipeline --flag PIVOT_HARD TARGET brainweb-v2 \
     --force-reset --message "Product fundamentally misaligned"

# Product reset for pivot:
product-reset --mode PIVOT --trigger GROWTH_FAILURE \
     --start-new-foundation
```
