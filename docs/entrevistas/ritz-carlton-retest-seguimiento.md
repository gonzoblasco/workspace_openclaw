## Lecciones del proceso

1. **"Test de logica" de un recruiter puede ser JS tecnico** - confirmar formato antes (psicotécnico vs programacion). El 27/08 se preparo lo equivocado.
2. **Pregunta de ubicacion/IP = deteccion de proxy/VPN**, no bandera negativa. Responder rapido y proactivo (ofrecer IP) despeja dudas.
3. **Idioma: proceso 100% en ingles.** El desliz del 31/08 ("ahi desactive mi proxy") fue el recordatorio. Toda comunicacion en ingles, siempre.
4. **Relacion con el recruiter = activo.** Samarth se tomo el 60% con humor, pidio el retest el mismo dia, hizo check-in casual el domingo, y uso "Chat GPT" para entender el espanol. Tenerlo de aliado vale mas que cualquier numero.
5. **El 69% confirma que acronimo + event loop estan solidos**; el punto perdido probablemente fue otro ejercicio de codigo. Si hay 3er intento, repasar algoritmos (reverse, countLetters).
