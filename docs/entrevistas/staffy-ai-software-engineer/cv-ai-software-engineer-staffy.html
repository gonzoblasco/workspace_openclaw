Open Source: Merged Pull Requests

Merged fixes in production component libraries, each shipped with regression tests and maintainer review.

  • facebook/astryx #4605 - Breadcrumb current item distinguished from links only by color, failing WCAG 1.4.1. Fixed by adding font weight so the state is conveyed without relying on color; the existing aria-current was preserved.
  • facebook/astryx #4914 - CI hard-failed with "no merge base" on any PR more than 50 commits behind main, because a shallow clone cannot resolve a three-dot diff. Fixed by deepening the clone and retrying, then falling back to a two-dot diff only as a last resort - and recording the diff mode so the approximate path is visible in the report instead of silently under-reporting changed components.
  • facebook/astryx #5419 - HoverCard with a label pointed its trigger's aria-describedby at a dialog, flattening structured content into a plain-text description and never telling the user the trigger opens a dialog. Replaced with the correct popup contract (aria-haspopup=dialog, aria-controls, aria-expanded synced to state), kept the old prop as a deprecated alias, and preserved the group fallback for unlabelled cards. 38 tests.
  • facebook/astryx #5493 - TreeList destructured a fixed set of props with no rest spread, so every aria-*, role, tabIndex and id promised by its base props contract was silently dropped before reaching the DOM. A tree without a visible header could not be named at all. Fixed by forwarding the rest props and routing aria-label and aria-labelledby onto the role=tree element itself. 78 tests.
  • mui/base-ui #5551 - Grid-based Combobox and Autocomplete rendered aria-orientation on a role that does not support it. Moved ARIA ownership out of the navigation hook and into the components that assign the final role, omitting it from grid and presentation roles while preserving two-dimensional keyboard navigation. 7 files, regression coverage per component.
  • mui/material-ui #49003 - Hidden carousel slides kept their links in the tab order, a WCAG 4.1.2 aria-hidden-focus violation surfaced by an axe-core audit. Made the slide link focusable only on the active slide.
  • adobe/react-spectrum #10503 - ComboBox announced every focused-item change through a live region, which interrupted and replaced VoiceOver's richer native announcements (selected state, role, item count) with just the item name. Gated the manual announcement to section changes only, where VoiceOver is silent, keeping section title and option count. 259 tests across both packages, with a documented scenario matrix. Merged with two maintainer approvals.
  • adobe/react-spectrum #10554 - Test-only regression locking global aria-posinset across virtualized sections, so a future refactor of the index computation cannot silently reintroduce per-section restart. Verified to pass against main; no production changes.
  • carbon-design-system/carbon #22887 - ComposedModal had no way to expose aria-describedby, which meant modal descriptions could not be associated with the dialog. Added the prop and wired it through both render paths: the native dialog element when the feature flag is on, and the div[role=dialog] fallback.
  • carbon-design-system/ibm-products #9878 - Focus was lost on step change in CreateFullPage. The active-step lookup walked the DOM for an [inert] ancestor, but steps are hidden with a CSS class instead, so the walk always returned the first step and called focus() inside a display:none subtree - a browser no-op, leaving focus on the skip link. Replaced with a direct query for the visible-step class; the regression test fails on main and passes with the fix. 28 tests.
  • carbon-design-system/ibm-products #9879 - Datagrid sortable headers carried aria-pressed, so screen readers announced them as toggle buttons and never conveyed sort direction. Removed it and let aria-sort on the columnheader carry the state, matching core Carbon DataTable behavior. 47 tests.
