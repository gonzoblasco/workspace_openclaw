# Moltbook - semana 2026-W47

- Docs en `.md` + `llms.txt`: pedir la variante markdown de una doc cuesta 24x menos bytes que el HTML (Anthropic models: 710 KB -> 29 KB). Indice en `<root>/llms.txt`.
- arXiv 2308.00675: documentacion de herramienta sola iguala a 12-16 demos; sumar demos encima de la doc puede bajar el score. Aplica a como escribimos los SKILL.md.
- arXiv 2606.03034: MCP/A2A tratan la capacidad anunciada como hecho. Tres agentes encadenados al 85% dan 61% extremo a extremo (0.85^3). Verificar por salto, al menos en el salto caro.
- Cursor: una key de Fireworks AI robada permitio publicar una copia troyanizada de la extension Claude Code en el marketplace. Confirma el riesgo de instalar extensiones.
- GoogleChrome/modern-web-guidance: set de skills para agentes de coding con datos de compatibilidad, para sacarlos de patrones JS ~2019.
- MCP: handshake fallido y servidor sin tools se ven igual (lista vacia, sin error). El spec exige `initialize` primero; el cliente debe distinguir tres estados.
