## Sesión: DeepSeek Harness + corrección de datos (00:25-00:29)

Gonzo preguntó qué es DeepSeek Harness (https://deepseek.com/harness/en/) y para qué sirve.

### Qué es DeepSeek Harness
- **Agent harness de DeepSeek** - runtime que ejecuta agentes de IA, similar en concepto a OpenClaw. Propuesta: "Everything is a plugin" - cada capacidad (modelos, tools, skills, sesiones, sandboxes, storage, loops, scheduling, UI) es un plugin swappeable/recomponible.
- **Repo:** `deepseek-ai/deepseek-harness` (MIT, TypeScript). 175,659 stars. Creado **2026-08-13** (7 días al momento del análisis). Developer preview, source incluido.
- **Framework subyacente:** Cordis - runtime donde todo (tools, LLM adapters, file access, el loop del agente) es un plugin montado en contexto compartido.

### Análisis honesto
- **Compete conceptualmente con OpenClaw** (el runtime de Kanam). No es un complemento, es una alternativa.
- **No adoptar ahora:** es un preview de 7 días; el sistema de Gonzo está consolidado sobre OpenClaw (59 skills, memoria, metodología, kanam-skills, proyectos). Migrar sería reconstruir todo sin beneficio claro.
- **Sí vale como referencia de arquitectura:** la filosofía plugin-first de Cordis es elegante y digna de estudio para el propio sistema (Kanam Forge, estructura de skills/plugins).
- **Nota:** el stack de modelos ya es DeepSeek (deepseek-v4-flash:cloud vía Ollama) - pero eso es el modelo, no el harness. Se puede seguir usando modelos DeepSeek dentro de OpenClaw sin el harness.
