Gonzo me pasó el PR #7834 (`use safeStringify for loader dependency hash keys`) para revisar. Trabajo en repo externo (fork `gonzoblasco/gonzoblasco-router`), no proyecto del workspace.

### Timeline de la sesión
1. **Comentario de CodeRabbit** (bot) - "no actionable comments", pero 1 warning (Linked Issues) empujando al search serializer. Lo descarté: era la dirección opuesta a lo que pidió el humano.
2. **Comentario humano de schiller-manuel** (maintainer): *"we wont merge this as is, this too niche and its bundlesize impact is not warranted for all users. possibly we could allow letting a user configure a custom stringifier for loaderDeps."* → Rechazo con redirección: hacerlo **configurable opt-in**.
3. **Iteración 1 (commit `359fb9bb21`)**: nueva opción `stringifyLoaderDeps` (default `JSON.stringify`), `safeStringify` exportado como utilidad. 1583 tests verdes.
4. **Review de CodeRabbit** tras el push: 1 major (colisión de tipos en safeStringify) + 2 minor (llaves, `any`→`unknown`) + inline (default revienta con bigint).
5. **Iteración 2 (commit `5834442668`)**: safeStringify collision-proof (prefijo tag `\u0000` + escape por duplicación), default robusto `defaultStringifyLoaderDeps` (JSON.stringify + fallback safeStringify), type safety, 7 tests de regresión. 1632 tests verdes.

### Decisiones técnicas
- **safeStringify collision-proof:** valores especiales (bigint, Set, Map, undefined, Date, function, symbol, circular) usan prefijo tag reservado `\u0000`. Strings de usuario que empiecen con el prefijo se escapan duplicándolo. Así `123n` ≠ `'123n'`, `undefined` ≠ `''`, `Date` ≠ ISO string.
- **Default robusto:** `defaultStringifyLoaderDeps` = JSON.stringify para deps planas (sin peso extra) + fallback a safeStringify cuando lanza (bigint). Nota: JSON.stringify NO lanza con Set/Map (devuelve `{}` silenciosamente) - solo bigint lanza. Para Set/Map hay que pasar safeStringify explícito.
- **Le di la razón al humano, no al bot:** CodeRabbit empujaba al search serializer (lo que schiller-manuel rechazó en #7818); el humano pidió configurable opt-in. Seguí al humano.
