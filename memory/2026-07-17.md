## Lessons Learned

1. **Regeneration > Refactoring**: When legacy codebase has unapplied decisions, starting fresh is better than incremental refactoring.

2. **Document first**: ADRs + BRIEF before implementation prevents bad technical decisions from propagating.

3. **Testing in layers**: Separate rendering tests (Vitest), keyboard tests (user-event), and accessibility audits (axe-core). Better coverage.

4. **Modern stack velocity**: Vite 6 builds faster than old Webpack setup for same codebase.

5. **Git workflow correctness**: Working on `main-oss-next` fork preserves upstream repos while enabling local experimentation.
