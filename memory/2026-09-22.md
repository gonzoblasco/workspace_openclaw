## Learnings - 2026-09-22

### using-agent-skills was dangerous
**What happened:** Gonzo noticed Kanam getting off-scope in recent sessions, doing things not asked for. Root cause analysis showed using-agent-skills had a 16-step lifecycle sequence that encouraged chaining skills for any non-trivial task, generating work not requested.
**Decision:** Eliminated the skill. The good parts (decision tree, core operating behaviors) live in AGENTS.md and SOUL.md already.
**Lesson:** Skills with long lifecycle sequences can cause drift. When a skill encourages "apply this sequence" by default, it over-engineers simple requests.

### Image generation fails with 402
**What happened:** Tried to generate a diagram via OpenRouter image generation. Got HTTP 402 (insufficient credits).
**Status:** image-generation skill was eliminated anyway. OpenRouter credits depleted.
**Lesson:** Before attempting image generation, check OpenRouter credit balance.

### OpenSpec pattern was a stub
**What happened:** openspec-pattern had 27 lines, status PENDING_REVIEW. Was proposed as consolidation target but was itself an empty shell.
**Lesson:** When evaluating merges, verify the target skill actually has content. Several "consolidation targets" were themselves stubs waiting to absorb their siblings.

### Skills language split
**Rule confirmed (AGENTS.md):** GitHub surface = English; workspace private = Spanish. Skills in Spanish (cv-tailor, interview-me, session-lifecycle references in Spanish) are private use only. The sanitize-skills.py script handles personal data but does not translate. i18n before publishing to kanam-skills requires manual rewrite, not just sanitization.

### 4 commits in one session is acceptable
**What happened:** Pre-commit hook failed twice due to em-dashes in content-crafting and design-cycle (Spanish skills), and missing package.json. Fixed each time and recommitted.
**Lesson:** Pre-commit failures are informational, not blocking. Fix and recommit.
