## Lecciones

- **Siempre correr `lint:fix` + `typecheck` + `test:run` antes de commitear.** No hay commits de fixes.
- **Los templates no se compilan con tsc.** Hay que copiarlos a `dist/` post-build.
- **El lockfile de npm en macOS tiene deps platform-specific.** Usar `npm install` en vez de `npm ci` en CI.
- **Biome `includes` reemplaza el default.** Mejor no usarlo si no es necesario.
- **No trabajar el mismo repo desde dos sesiones simultáneas.** Riesgo de pisarse.
