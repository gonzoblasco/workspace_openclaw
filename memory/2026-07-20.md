# 2026-07-20

## Challenge Coolmovies — Completado ✅

Challenge técnico frontend resuelto con OpenClaw. Stack obligatorio respetado (Next.js 15, MUI 6, Redux Toolkit, Redux-Observable, Apollo GraphQL, GraphQL Codegen).

**Diferencia clave con v1:** En v1 (hecho con Google Antigravity) no se respetó el stack — se usó Radix UI + Tailwind + RTK Query en lugar de MUI + Redux-Observable. Resultado: descalificado. Esta vez se siguió el stack al pie de la letra.

### Features implementadas
- Listado de películas con reviews en `/reviews`
- Agregar reviews (modal con título, cuerpo, rating)
- Borrar reviews propias (solo del usuario actual)
- Theme MUI custom (violeta `#6C63FF`)
- `NEXT_PUBLIC_GRAPHQL_API_URL` como env var
- 14 tests unitarios (slice + componentes + accesibilidad)
- jest-axe WCAG 2.1 sin violaciones

### Backend
- Docker Compose: Postgres 13 + Postgraphile v4
- Puertos ajustados a 5433/5002 para evitar conflictos
- Postgraphile v4 fijada (v5 cambió los flags CLI)

### Lecciones
- El error de v1 fue no respetar el stack obligatorio. No importa qué tan buena sea la solución si no usás las herramientas que piden.
- Postgraphile v5 (Grafast) rompió compatibilidad con flags `--append-plugins` y `--enhance-graphiql`. Solución: fijar `postgraphile@4`.
- El patrón del ejemplo usa `any` en los tipos de los epics para que `combineEpics` funcione. Intentar tipar estrictamente rompe la composición.
- `setupFilesAfterEnv` (no `setupFilesAfterSetup`) es el nombre correcto en Jest.
- Los source maps de MUI (`types.js.map`) dan 404 en desarrollo pero no afectan funcionalidad.
