## OSS: radix-ui/primitives #3701 — PR #4053

- Agarré el issue #3701: Select dentro de Dialog congela el foco en React 19.
- Root cause: el FocusScope del Dialog atrapa el foco, y el portal del Select está fuera del DOM del Dialog. El FocusScope del Dialog reclaims el foco cuando se mueve al portal del Select.
- Fix: agregar `useFocusScopeBranch(content)` en SelectContentImpl para registrar el portal como branch del FocusScope ancestro (el Dialog).
- Tests: 43 tests pasan (Select 17, Dialog 15, FocusScope 11).
- PR: https://github.com/radix-ui/primitives/pull/4053
- Lección: los componentes porteados necesitan registrarse como branches del FocusScope ancestro para que el focus trapping funcione correctamente.

- Agarré el issue #17216: duplicate latest=true version rows bajo autosave en D1/SQLite.
- Root cause: createVersion usa updatedAt < para limpiar latest flags anteriores, pero writes en el mismo segundo tienen el mismo updatedAt y el < no los agarra.
- Fix: reemplazar updatedAt < por id < result.id. Los IDs son auto-incrementales, así que cualquier versión anterior siempre tiene un id menor.
- Tests: assertion adicional en parallel-writes test + nuevo test de same-second writes.
- 108 tests pasan en SQLite.
- PR: https://github.com/payloadcms/payload/pull/17413
