## BUG EXPLAIN (encontrado por Gonzo probando la app)

- **Sintoma:** "ollama returned an empty response" al apretar Explain this audit
- **Causa raiz:** modelos de razonamiento (qwen3.5:9b-mlx, deepseek-v4-flash) emiten `thinking` largo que consume num_predict, dejando response vacio (done_reason: length)
- **Fix:** `think:false` en el payload de /api/generate (explainAudit)
- **Fix 2:** default model -> deepseek-v4-flash:cloud (rapido ~2s) configurable via KANAM_PULSE_AI_MODEL
- Verificado end-to-end: 450+ chars de explicacion humana (firewall off + memoria alta)
- Commits: 05e9412 (fix), 6141cf4 (perf model)
