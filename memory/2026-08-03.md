**Fix:** Reemplazar `***` por `$((PASS + 1))` en los 7 archivos con el mismo patrón. `knowledge-audit.sh` necesita `shopt -s nullglob` o usar `find`.

### Bash — bugs de runtime (3)
| Script | Bug |
|---|---|
| `copy-editing/scripts/word-count.sh:30` | `PARAGRAPHS=$(grep -cE '^[[:space:]]*$' || echo 0)` falla con `set -e` cuando grep no encuentra match (devuelve exit 1, OR lo rescata pero el output incluye "0" pegado al número) |
| `narrative-content/scripts/progress-tracker.sh:123` | Mismo patrón: `grep -cE` sin `\|\| true` rompe arithmetic expansion |
| `engineering-governance/scripts/detect-duplicates.sh` | `grep -i integrationwithotherskills` (palabra pegada, debería ser "Integration with other skills" o similar) + `set -e` mata el script en `head -1` cuando no matchea. Exit 1 sin output útil |
| `tech-docs/scripts/generate-adr.sh` | `grep -oP` no soportado en macOS BSD grep. Calcula mal el número de ADR (siempre 001). Fix: usar `grep -oE '[0-9]+' \| sort \| tail -1` |

## Lecciones

1. **`bash -n` no detecta todos los bugs** — 3 bugs aparecieron solo en runtime.
2. **El patrón `***` en contador es un tell de copy-paste** — 7 archivos con el mismo bug.
3. **`set -euo pipefail` muerde** — especialmente con `grep -c`, `grep -o`, globs.
4. **Code review rápido patea la puerta a refactors** — el fix de `detect-duplicates.sh` funciona, pero la arquitectura sigue siendo frágil.
5. **Necesitamos tests automatizados** — 95 scripts a mano no es sostenible.
