## Bugs encontrados

### Bash — sintaxis rota (8)
Patron `PASS=*** + 1))` en lugar de `PASS=$((PASS + 1))` (probablemente copy-paste malformado desde una variable `***` que se comio los caracteres):

| Script | Linea |
|---|---|
| `release-management/scripts/release-check.sh` | 34 |
| `vibe-code-cleanup/scripts/verify-cleanup.sh` | 20 |
| `pre-deploy-qa/scripts/pre-deploy-check.sh` | 34 |
| `pre-deploy-qa/scripts/smoke-test.sh` | 23 |
| `observability/scripts/health-check.sh` | 35 |
| `review-quality/scripts/security-scan.sh` | 22 |
| `review-quality/scripts/review-pr.sh` | 31 |
| `knowledge-management/scripts/knowledge-audit.sh` | 69 (for loop syntax: `for kdir in projects/*/.knowledge 2>/dev/null`) |

**Fix:** Reemplazar `***` por `$((PASS + 1))` en los 7 archivos con el mismo patron. `knowledge-audit.sh` necesita `shopt -s nullglob` o usar `find`.

### Bash — bugs de runtime (3)
| Script | Bug |
|---|---|
| `copy-editing/scripts/word-count.sh:30` | `PARAGRAPHS=$(grep -cE '^[[:space:]]*$' || echo 0)` falla con `set -e` cuando grep no encuentra match (devuelve exit 1, OR lo rescata pero el output incluye "0" pegado al numero) |
| `narrative-content/scripts/progress-tracker.sh:123` | Mismo patron: `grep -cE` sin `|| true` rompe arithmetic expansion |
| `engineering-governance/scripts/detect-duplicates.sh` | `grep -i integrationwithotherskills` (palabra pegada, deberia ser "Integration with other skills" o similar) + `set -e` mata el script en `head -1` cuando no matchea. Exit 1 sin output util |
| `tech-docs/scripts/generate-adr.sh` | `grep -oP` no soportado en macOS BSD grep. Calcula mal el numero de ADR (siempre 001). Fix: usar `grep -oE '[0-9]+' | sort | tail -1` |

## Lecciones

1. **`bash -n` no detecta todos los bugs** — 3 bugs aparecieron solo en runtime.
2. **El patron `***` en contador es un tell de copy-paste** — 7 archivos con el mismo bug.
3. **`set -euo pipefail` muerde** — especialmente con `grep -c`, `grep -o`, globs.
4. **Code review rapido patea la puerta a refactors** — el fix de `detect-duplicates.sh` funciona, pero la arquitectura sigue siendo fragil.
5. **Necesitamos tests automatizados** — 95 scripts a mano no es sostenible.
6. **Permisos importan** — `progress-tracker.sh` no era ejecutable y paso desapercibido en el primer audit.
7. **El patron `cmd || echo "0"` con `grep -c` es peligroso** — produce `0\n0` y rompe arithmetic expansion. Usar `|| true` + default es mas seguro.
8. **`sed` con `&` en macOS** — `sed 's/.*/\u&/'` no capitaliza. Usar `awk` o `perl`.
9. **`PASS=***` inicial era tan danino como `PASS=*** + 1))`** — ambos rompen el contador. El `bash -n` no detecta el inicial.
10. **Los `find` sin parentesis son trampas** — `find A -name B -o -name C -exec ...` solo aplica `-exec` al segundo `-name`. Siempre usar `\( ... \)` con OR.
11. **Los escapes de `\|` en bash son literales dentro de single quotes** — `grep -E 'a\|b'` busca literal `a|b`; para regex OR usar `'a|b'`.
12. **grep case-sensitive es inutil para secret detection** — `API_KEY`, `Token`, `Secret` son formas comunes. Usar `-i`.
13. **El `tail -N` para parsear bisect output depende de idioma y formato** — es fragil. Ideal: parsear por delimitador o usar `git bisect log`.
14. **Eliminar `eval "$cmd"` reduce superficie de ataque** — aunque los comandos sean hardcodeados hoy, el refactor obliga a funciones con nombres.
15. **Los helpers de fecha deben centralizarse** — `add_days`, `date_yesterday` evitan repetir fallback macOS/GNU en cada script.
16. **`.knowledge/` en `.gitignore` de proyecto es consistente con la metodologia** — la memoria institucional vive en workspace, no en repo del proyecto.
17. **`sed -i` nunca es portable directamente** — macOS requiere extension, GNU no. Usar `sed -i.bak` + `rm .bak` en ambos.
18. **Tests automatizados pagan la inversion inmediatamente** — el primer run de `npm test` detecto que `word-count.sh` con archivo vacio daba exit 1 por `grep` sin matches. Se arreglo antes de commitear.
