## Resumen
Revisión, feedback y refinamiento de las 7 nuevas skills workflow que reemplazan las 30 skills anteriores. Se partió `workflow-content-docs` en dos (tech-docs + narrative-content) y se ajustaron las otras 6 con feedback detallado.

- **workflow-narrative-content** — ficción, novelas, worldbuilding, personajes. Reemplaza story-planning, story-writing, umbrawriter-oss-v01-ai-copilot-structure.

- **workflow-review-quality** — tests obligatorios, security audit adaptativo.

## Aprendizajes
- content-docs mezclaba procesos muy dispares (ADRs técnicos con story writing de ficción). Partirlo fue la decisión correcta.
- Los detalles finos de cada skill original (lecciones de TanStack, criterios de fork vs isolated, nivel de conformidad WCAG) no deben perderse en la unificación.
- El taller de skills (skill_workshop) permite crear propuestas, revisarlas, y aplicarlas sin afectar las skills activas hasta el momento de aplicar.
