## Sobre sesiones entre máquinas
- Las sesiones de OpenClaw viven localmente en cada máquina (en el gateway), no en el repo
- Cada máquina tiene su propio historial de conversaciones
- El workspace compartido (MDs) es la "memoria compartida" que se sincroniza via git
- Beneficio: dos sesiones distintas = dos ángulos de la misma idea, lo que se decide se registra en los MDs

## Spec-Driven Development (SDD) — investigación e integración en CSN
- Gonzo escuchó sobre SDD y lo relacionó con CSN (docs como fuente de verdad para IA)

## shadcn-ui/ui — PR #11179 (issue #11157)
- Forkeado shadcn-ui/ui → github.com/gonzoblasco/ui
- Clonado en `projects/ui`, remotes: `fork` + `upstream`
- Issue #11157: Input OTP keyboard navigation causes unwanted layout shift
- Root cause: `transition-all` en InputOTPSlot anima todas las propiedades CSS cuando `data-active` cambia al hacer Tab/Shift+Tab
- Fix: `transition-all` → `transition-[color,box-shadow]` en 15 archivos (14 style variants + 1 registry new-york-v4)
- PR abierto: https://github.com/shadcn-ui/ui/pull/11179
- Competencia: PR #11160 de Emran-Y tiene el mismo enfoque pero le faltó el registry new-york-v4 (14 archivos vs nuestros 15)

## shadcn-ui/ui — PR #11180 (issue #11161)
- Issue #11161: MessageScroller "Reading Scroll State" demo flicker en narrow viewports
- Root cause: feedback loop layout ↔ scroll-state — el footer cambia de altura cuando el texto de status envuelve a 2 líneas, cambiando el viewport, que recalcula scrollability, que cambia el status, loop infinito
- Fix: `<span className="flex min-h-[2lh] items-center">` en el CardFooter del ejemplo (base + radix)
- PR abierto: https://github.com/shadcn-ui/ui/pull/11180
- Sin PRs competidores
- Issue #11104 descartado: 4 PRs competidores ya abiertos
