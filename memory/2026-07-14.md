## Sobre sesiones entre máquinas
- Las sesiones de OpenClaw viven localmente en cada máquina (en el gateway), no en el repo
- Cada máquina tiene su propio historial de conversaciones
- El workspace compartido (MDs) es la "memoria compartida" que se sincroniza via git
- Beneficio: dos sesiones distintas = dos ángulos de la misma idea, lo que se decide se registra en los MDs

## Spec-Driven Development (SDD) — investigación e integración en CSN
- Gonzo escuchó sobre SDD y lo relacionó con CSN (docs como fuente de verdad para IA)
- Investigamos las 3 herramientas principales: GitHub Spec-Kit (Python, 118k stars), OpenSpec (TypeScript, 59k stars), SpecD
- **OpenSpec** es el ganador: TypeScript, MIT, npm, flujo explore→propose→apply→archive
- OpenSpec usa delta specs (ADDED/MODIFIED/REMOVED) — bueno para brownfield
- Decisión: integrar OpenSpec en CSN **como parte del scaffold base**, no como flag opcional
- Camino elegido: ejecutar `openspec init` post-scaffold con fallback a estructura pre-armada en el template
- Versión objetivo: 0.7.0
- Lección: CSN es 100% en español — hasta los release notes. No escribir en inglés
