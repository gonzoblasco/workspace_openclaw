## Lecciones

- Biome + tests no detectan errores de runtime ES (imports duplicados, referencias rotas). El build es el verdadero gate.
- No encadenar build + commit en un solo comando si partes del flujo ya pueden haber commiteado. Verificar build *antes* del commit.
- El pre-commit hook es la última red de seguridad, no el primer paso.
