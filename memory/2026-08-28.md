- **Push + PR**: rama `refactor/estructura-modular` pusheada a `Breacorp/MODERNO_AI_CLEANER_PRO`, PR #1 abierto contra `main`.

### Decisiones clave
- **Compatibilidad de rutas**: `system.js` montado en `/api` (no `/api/system`) para preservar paths planos del frontend (`/api/system-metrics`, `/api/processes/kill`). `audit.js` queda en `/api/system` para `/api/system/full-audit`.
- **Sin bundler**: frontend como `<script>` tags en orden compartiendo scope global. Más simple, más cercano al toolchain original.
- **Tests en módulos puros**: format/security/paths son los únicos testeables sin mockear sistema.
- **Quirk de formatSize documentado, no corregido**: valores exactos (`1 GB`) pierden el `.00` por `parseFloat`. Corregirlo cambiaría labels de UI (fuera de scope estructural).

### Gateway cayéndose (problema de entorno)
El gateway se reiniciaba suave bajo cadenas largas de exec en serie. No es crash (sin dump): es reinicio del bridge/WebSocket. Solución: agrupar validaciones en scripts `.sh` de un solo exec. Lección registrada en `docs/learnings/infraestructura.md`.
