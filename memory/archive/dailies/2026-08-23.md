## Spike ForgeCode - probado y descartado - sesión 21:44-21:54

**Contexto:** Gonzo pasó una lista de ~30 herramientas de código para evaluar. De toda la lista, ForgeCode era la única que valía un spike real (harness Rust open source, lideraba TermBench 2.0 con 81.8%, filosofía alineada con "IA como infraestructura").

**Qué se probó:** instalé Forge 2.13.21, lo configuré para Ollama (provider nativo, soporta deepseek-v4-flash:cloud), y probé arrancarlo.

**Resultado: NO FUNCIONA para nuestro caso. Descartado.**

**Por qué (causa raíz verificada):**
- Forge NO arranca en entornos headless (sin TTY real). Cualquier comando que inicialice credenciales (`forge -p`, `forge config set model`, `forge provider login`) falla con `ERROR: Device not configured (os error 6)`.
- Causa raíz (confirmada en doc oficial `forge_config::secret_store`): Forge usa el keyring de macOS primero, y en entornos headless el keyring falla. El fallback a archivo encriptado no se ejecuta bien en la fase de migración de credenciales.
- Con un PTY real (via `expect`) Forge SÍ arranca y muestra su flujo de autenticación de Ollama (SSL -> host -> modelo), pero automatizar esa TUI con expect es frágil e incompleto.

**Conclusión para no repetir a futuro:** ForgeCode (y por extensión los harnesses de terminal tipo Claude Code) son aplicaciones de terminal interactivo (TUI) que necesitan TTY real para arrancar CUALQUIER sesión, no solo el setup inicial. No son orquestables por un agente en entornos headless. Nuestro pipeline A/B depende de que Kanam orqueste los agentes desde el agente (Qwen Code via `ollama launch qwen`, Claude Code via ANTHROPIC_BASE_URL). **No volver a evaluar ForgeCode ni harnesses similares que requieran TTY interactivo en su uso normal.** Matiz: esto es un límite del entorno del agente, no de la herramienta - Forge funcionaría en el terminal interactivo de un humano.

**Dato extra del spike:** el #1 de ForgeCode en TermBench 2.0 es su propio benchmark (tbench.ai), no neutral. En SWE-bench Verified (independiente) la ventaja se reduce a ~2.4 puntos vs Claude Code. El liderazgo era "benchmaxxed".

**Estado del sistema:** desinstalado completo. Binario `~/.local/bin/forge` removido, `~/.forge/` eliminado, dependencias que instaló (fzf, bat, fd en `~/.local/bin/`) removidas. Sistema quedó como estaba antes del spike.
