### Proyecto: Kanam Fixer V0.2.0
**Ubicación:** `projects/kanam-fixer-v2/`
**Concepto:** De "bot de reportes" a "motor de remediación automática". No solo detecta, ARREGLA.

** stack:**
- TypeScript + Node
- Playwright + Axe-core (detección)
- ts-morph (transformación AST)
- Commander + Chalk (CLI profesional)

**Estructura:**
```
src/
  core/
    analyzer.ts     # Browser -> Axe-core
    registry.ts     # Axe ID -> Remediator mapper
  remediators/
    types.ts        # Interface del remediador
    interactive-div.ts  # div -> button
    alt-text.ts     # img sin alt -> inferencia de alt
  index.ts          # CLI orchestrator
tests/fixtures/
  BuggyComponent.tsx  # Campo de pruebas
```

**Features Implementadas:**
- CLI con `--dry-run`, `--url`, `--path`
- Mapeo Browser DOM -> Source Line (`data-source-loc`)
- RemediationRegistry (módulo, expandible)
- AltTextRemediator con inferencia semántica (decorativa vs contenido)
- Bucle de Verificación: Scan -> Fix -> Scan -> Confirmación

**Pendiente / Deuda Técnica:**
- El mapeo línea exacta depende de `data-source-loc` en el componente (instrumentación manual)
- Quedó el problema de `ts-node` en Node v26 (se usó `tsx` como workaround)
