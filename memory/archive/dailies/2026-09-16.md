- **Recomendación (con evidencia hoy):** para prompts de algoritmos/estructuras pesadas usar minimax-m2.7 o qwen3.5. Evitar los flash (glm-5.3-flash, deepseek-v4-flash) para prompts de alta complejidad.

Además, los timeouts/heartbeat del navegador cortan la conexión si la request es muy larga (el server SÍ completa, pero el cliente ya no muestra). Para prompts pesados conviene probar UN modelo por vez, no 2 en paralelo con timing.
