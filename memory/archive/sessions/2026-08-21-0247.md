## Arbitraje simple: ¿Kimi o Flash?

Cada vez que el orquestador (yo) mande una tarea al pipeline, evalúo 3 cosas:

1. **¿Requiere multimodal?** (imagen, screenshot, diagrama, PDF visual) → **Kimi**
2. **¿Es un review/debug con ambigüedad real?** (test falla sin motivo obvio, lógica de negocio cruzada, bug no trivial) → **Kimi**
3. **¿Es contexto extenso donde flash tiende a perderse?** (archivos grandes, diff grueso, refactor de múltiples módulos) → **Kimi**

Si ninguna aplica → **Flash**

## Reglas de veto

- Si la semana está por encima del 85% de uso → default a Flash salvo multimodalidad obligatoria.
- Si una tarea ya fue intentada con Flash y falló → retry con Kimi automáticamente.
- Review de cambios simples (tipado, imports, estilo) siempre Flash.
