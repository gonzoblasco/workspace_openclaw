## Tutorial: usar LM Studio como backend de OpenClaw

### 1. Instalá y abrí LM Studio
- Bajalo de [lmstudio.ai](https://lmstudio.ai) (hay para Windows, Mac y Linux).
- Instalalo como cualquier programa. Abrilo.

### 2. Descargá un modelo
- En la pestaña **Search** (lupa), buscá un modelo, por ejemplo `qwen2.5` o `llama 3.2`.
- Cliqueá el modelo y dale **Download**.
- Esperá a que baje (es grande, 1-4 GB según el modelo).

### 3. Cargá el modelo y levantá el servidor local
- Andá a la pestaña **My Models** y cliqueá el modelo para **cargarlo** (Load).
- Ahora andá a la pestaña **Local Server** (o "Developer" según versión).
- Ajustá el puerto. El **default es `1234`** - no lo cambies si no sabés qué hacés.
- Dale **Start Server**.

✅ En este punto LM Studio ya está exponiendo una API estilo OpenAI en:
```
http://localhost:1234/v1
```

## Ahora apuntá OpenClaw a LM Studio

Esto se hace en la **config de modelos** de OpenClaw. Depende de cómo lo tengas (CLI con `openclaw` o la web del Gateway). La idea es la misma en todos: declarar un provider con base URL apuntando a LM Studio.

En tu `openclaw.json` (o `config`), un ejemplo de bloque que suma LM Studio como provider:

```json
{
  "models": {
    "providers": {
      "lmstudio": {
        "baseUrl": "http://localhost:1234/v1",
        "apiKey": "***"   // LM Studio no valida, poné lo que quieras
      }
    }
  }
}
```

Y después usás el modelo como:
```
lmstudio/qwen2.5
```

Ojo: el nombre exacto del modelo tiene que coincidir con el que cargaste en LM Studio.

---

Si no querés tocar JSON a mano, en la **UI del Gateway** andá a la sección de modelos y agregá un provider/custom endpoint con la base URL `http://localhost:1234/v1`.

## Checklist rápida si algo no anda

1. **¿Está el server prendido?** En LM Studio, pestaña Local Server → Start Server. Debe decir "Running".
2. **¿El puerto es el mismo?** OpenClaw y LM Studio tienen que usar el mismo puerto. Default 1234.
3. **¿Nombre del modelo exacto?** Tiene que coincidir letra por letra con el que cargaste en LM Studio.
4. **¿Modelo cargado?** A veces hay que hacer Load manualmente antes de usarlo.
5. **Probalo solo:** en el navegador andá a `http://localhost:1234/v1/models` y deberías ver el listado de modelos. Si eso anda, OpenClaw va a poder conectarse.
