# blogwatcher

## Descripción
CLI tool para trackear actualizaciones de blogs y feeds RSS/Atom. Se agregan feeds por URL, se escanea contenido nuevo, y se gestiona estado read/unread desde la terminal.

## Cuándo usarlo
- Para revisar posts nuevos en múltiples tech blogs cada mañana
- Para trackear el blog de un autor favorito sin abrir el browser
- Para monitorear feeds RSS durante sesiones de desarrollo
- Para mantener una lista de lectura personal organizada por línea de comandos

## Workflow
1. Agregar feeds de interés (tech blogs, OSS, autores)
2. Periódicamente (diario en startup ritual o heartbeat), escanear feeds nuevos
3. Revisar los posts nuevos
4. Marcar como leídos los revisados

## Notas
- Sin dependencias externas
- Todo desde terminal, sin GUI
- Ideal para el startup ritual diario
