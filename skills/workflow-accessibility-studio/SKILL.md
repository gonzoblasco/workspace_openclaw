# Workflow: Accessibility Studio

## Skills que reemplaza
- `a11y-system-designer`
- `ux-a11y-studio`

## Qué hace
Diseño y validación de accesibilidad en productos digitales.

## Fases
1. **Discovery** — usuarios con discapacidades, necesidades, contexto
2. **Audit** — WCAG 2.2. Especificar nivel de conformidad objetivo (A, AA, AAA) al inicio. Automated (axe-core) + manual: keyboard, screen reader, cognitive, visual
3. **Design System** — tokens de contraste verificado, componentes accesibles
4. **Implementación** — componentes headless (WAI-APG), 3 capas de tests
5. **Validación** — pre-launch, regresión, reporte de cumplimiento. Si es posible, pruebas con usuarios reales con discapacidades. Si no, documentar las limitaciones

## Outputs
- Reporte de audit WCAG 2.2 con nivel de conformidad
- Design system con contraste verificado
- Componentes accesibles con tests
- Certificación de accesibilidad pre-launch
