# Bug Patterns — Memoria del Debug Agent

Cada bug resuelto deja una entrada aquí. El agente consulta esta memoria antes de empezar una investigación nueva.

## Formato

```markdown
### YYYY-MM-DD: [Título corto del bug]

**Repo:** [nombre del repo]
**Síntoma:** [qué se observaba]
**Causa raíz:** [qué lo causaba]
**Patrón:** [categoría: null-check / race-condition / async / state / config / etc.]
**Fix:** [qué se cambió]
**Tags:** [etiquetas para búsqueda]
```
