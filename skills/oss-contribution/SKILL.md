# Workflow: OSS Contribution

## What it does

Strategic contribution to external repositories with Spec-Driven Development.

## Phases

### 1. Pipeline
Select target repositories, tier ranking.

### 2. Triage
Search for issues without competing PRs, evaluate impact.

### 3. Analysis
Understand the bug/feature, root cause analysis. Use the issue reporter's analysis. Complex issue ≠ complex fix. Check if the reporter already identified the root cause.

### 4. Implementation
Fork, branch, fix, tests, specification (as-built or delta).

### 5. PR
Signed commits, clear and human description (not generated). In Tier 0 repositories: avoid automation traces in commits and descriptions. Human description, not generated.

### 6. Community
Comment on related issues, cross-referencing. Do this after the PR, not before, to avoid noise if the PR doesn't proceed.

### 7. Batch
Status check of open PRs (🟢⚠️🔴).

## Outputs
- PRs to external repositories
- Specifications (as-built or delta)
- Open PR status report
