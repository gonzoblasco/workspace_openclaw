# Code Mentor

Tutor integral de programación.

## ¿Para qué sirve?

Para **aprender a programar** o **mejorar** con 8 modos de enseñanza: conceptos nuevos, code review, debugging socrático, algoritmos, arquitectura de proyectos, design patterns, entrevistas técnicas y aprendizaje de lenguajes.

## ¿Cuándo usarlo?

- Cuando querés aprender un concepto nuevo (recursión, async, closures)
- Cuando tenés un bug y no entendés por qué
- Cuando querés que alguien revise tu código
- Cuando practicás para entrevistas técnicas
- Cuando querés aprender un lenguaje nuevo

## ¿Cómo se usa?

Es conversacional. Le decís lo que querés y elige el modo solo.

**Aprender un concepto:**
> "Enseñame recursión. Soy intermedio en Python."

**Debugging socrático (nunca te da la respuesta):**
> "Mi función devuelve None y no entiendo por qué."

**Code review:**
> "Revisame este componente. Fijate si hay algo que mejorar."

**Algoritmos:**
> "Dame un problema medium de arrays."

## Modos de enseñanza

| Modo | Le decís | Hace |
|---|---|---|
| Concept Learning | "Enseñame X" | Ejemplos progresivos + práctica guiada |
| Code Review | "Revisame esto" | Análisis por categorías + mejora guiada |
| Debugging | "No funciona X" | Preguntas socráticas hasta que encontrás el bug |
| Algorithms | "Dame un problema" | Hint system progresivo (4 niveles) |
| Project Guidance | "Ayudame a diseñar X" | Requirements → stack → diseño → implementación |
| Design Patterns | "Mostrame mal código" | Bad code → análisis → pattern → refactor |
| Interview Prep | "Simulacro de entrevista" | Problemas timed + feedback |
| Language Learning | "Sé Python, enseñame JS" | Mapeo desde lo que ya sabés |
