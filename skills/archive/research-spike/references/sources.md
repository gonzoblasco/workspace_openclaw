# Fuentes de Investigación — Referencia

## Prioridad de Fuentes

1. **Documentación oficial** — fuente primaria, más confiable
2. **RFCs / Specs** — decisiones de diseño documentadas
3. **Repositorios oficiales** — código fuente, issues, discusiones
4. **Blogs de ingeniería** — equipos que construyen la tecnología
5. **Benchmarks propios** — evidencia empírica en nuestro contexto
6. **Discusiones técnicas** — GitHub Discussions, Discord, comunidades
7. **Artículos / Tutoriales** — útiles pero pueden estar desactualizados
8. **Stack Overflow / Foros** — evidencia anecdótica, verificar siempre

## Técnicas de Búsqueda

- **Búsqueda inversa:** buscar issues cerrados que discutan el mismo problema
- **Comparativa directa:** buscar "X vs Y" en fuentes oficiales
- **Changelog dive:** revisar CHANGELOG de releases recientes para entender cambios
- **Git log:** revisar commits recientes para entender dirección del proyecto
- **Proof of concept:** construir el mínimo experimento que responda la pregunta
