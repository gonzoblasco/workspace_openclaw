# Monitoring Suite — Skill

## Scope & Capabilities
- Health checks, uptime monitoring, and alerting configuration
- Log aggregation, metrics collection, and dashboard creation
- Anomaly detection, incident response, and post-mortem analysis
- Performance baselines and SLA/SLI tracking

## Key Principles
- **Signal over noise** — alert only on what matters, not everything.
- **Proactive detection** — catch issues before users notice them.
- **Actionable alerts** — every alert must include remediation steps.

## Boundary Constraints
- Do not generate code for application logic; focus on observability infrastructure.
- Keep dashboards focused — one metric per visualization, no clutter.
