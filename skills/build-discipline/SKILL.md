# build-discipline

## Descripción
Trackea compromisos diarios, streaks y hábitos para construir comportamiento consistente. Usa habit stacking (anclar nuevos hábitos a rutinas existentes) con check-ins diarios y revisiones semanales de patrones. Todos los datos quedan locales.

## Cuándo usarlo
- Para trackear un schedule de sueño de 30 días
- Para apilar una meditación de 5 minutos a una rutina matutina existente
- Para revisar qué compromisos se rompieron durante una semana de estrés
- Para configurar bloques de deep focus con recordatorios
- Para identificar qué pilar de hábito está afectando a los demás

## Workflow
1. Definir los hábitos a construir (con habit stacking)
2. Diariamente, hacer check-in de hábitos
3. Semanalmente, revisar patrones y streaks
4. Ajustar hábitos según los datos
5. Celebrar streaks y aprender de rupturas

- Todo local, sin dependencias externas
- Habit stacking reduce dependencia de fuerza de voluntad
- Ideal para ADHD: sistemas en lugar de disciplina
